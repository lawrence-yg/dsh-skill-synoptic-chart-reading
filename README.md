# synoptic-chart-reading

一个 **DeepSeek Harness（DSH）Skill**：判读中国天气图（地面气压场、850 / 700 / 500 hPa 高空图）与风云（FY-4B）卫星云图。

适合回答这类问题：

- 这张天气图/云图里，这个系统是什么？
- 它为什么形成？接下来会怎么演变？
- 几张文不同时次的图，能不能串成一个完整的天气过程？

**不适用**：只想问「明天要不要带伞」——那是查天气，不是读图。

## 它解决什么问题

大模型看天气图时最常见的两种错：

1. **拿像素当经纬度做线性换算** —— 圆锥/兰勃特投影下能偏几百公里
2. **时次不对齐就下结论** —— 08 时的高空图配 16 时的云图，8 小时足够让形势变样

这个 Skill 把「先建立分析契约、再校验图面要素、最后分层解释」固化成流程，并要求明确区分
**图上直接读到的** 与 **据此推断的**。

## 安装

把整个文件夹放进 DSH 工作区的 `skills/` 目录：

```
<你的工作区>/skills/synoptic-chart-reading/
├── SKILL.md
└── references/
    └── case-fy4b-20261024.md
```

DSH 会把它作为按需加载的 Skill 出现在技能目录里，描述见 `SKILL.md` 的 frontmatter。

> `SKILL.md` 必须在**仓库根目录**（也就是 skill 文件夹的根），不要多套一层。

## 内容

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 主体：分析契约、图面要素校验、分层判读规则、常见误判 |
| `references/case-fy4b-20261024.md` | 一个完整走完判读流程的实例（2026-10-24 华北—江淮大范围低云盖），可当模板套用 |

## 使用

安装后直接贴图提问即可，例如：

```
这是 08 时 500 hPa 高空图和 16:15 的 FY-4B 真彩云图，帮我解释这片云是怎么来的
```
